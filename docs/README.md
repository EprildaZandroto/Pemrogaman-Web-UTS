# KEEPLY — Sistem Manajemen Inventaris Barang

**KEEPLY** adalah aplikasi web berbasis **Sistem Manajemen Data Interaktif** untuk mengelola data barang, memantau stok inventaris, mendeteksi stok menipis, serta melakukan operasi tambah, ubah, dan hapus data barang secara terstruktur. Proyek ini disusun untuk memenuhi Ujian Tengah Semester (UTS) mata kuliah **Pemrograman Web 1** (Program Studi Sistem Informasi, Fakultas Teknologi Informasi, Universitas Adhirajasa Reswara Sanjaya).

---

## Fitur Utama
* **Struktur Halaman Web:** Antarmuka terstruktur menggunakan HTML5 untuk header, navigasi, form input, dan tabel daftar barang.
* **Tata Letak & Tampilan:** Penataan elemen visual menggunakan CSS agar rapi dan mudah dibaca di berbagai ukuran layar.
* **Interaktivitas & Pencarian:** Mendukung interaksi antarmuka dan pencarian data barang.
* **Manajemen Data PHP:** Mengelola alur data barang melalui skrip PHP (`Index.php`, `add_product.php`, `edit_product.php`, `delete_product.php`, dan `database.php`).
